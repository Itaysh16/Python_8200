## 🛠️ Featured Project: Terminal-Based Task Manager (Project 1)

A robust, object-oriented command-line interface (CLI) task management system built in Python. This application allows users to efficiently organize, track, and persist their daily tasks.

### ✨ Key Features
* **Object-Oriented Design:** Clean architecture utilizing `Task` and `TaskManager` classes for high modularity and separation of concerns.
* **Persistent Storage:** Automatically saves and loads tasks using **JSON format** (UTF-8 encoded), ensuring data is retained between sessions.
* **Interactive CLI Loop:** A user-friendly command-line menu allowing users to add tasks, view a numbered checklist, update task statuses, and delete items.
* **Robust Validation:** Built-in error handling and bounds validation to prevent crashes from invalid user inputs or missing files.
